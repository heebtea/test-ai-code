# Project Second Brain Lite v0.5

繁體中文生活紀錄工具。首次啟動為空白，**僅本機保存、尚未跨裝置同步**。資料保存在 localStorage 與 IndexedDB，圖片辨識也在瀏覽器本機完成。沒有帳號、後端、分析服務或外部資料上傳。不要把個人備份提交公開 GitHub。

本分支由 main `f850d27393a10314536655bb7b56f8d8d08ba2f1` 開發，供審查；未合併、未部署。舊 OCR 的移除與未合併修復原因見 [調查與交付](docs/v0.5-investigation.md)，測試範圍見 [VERIFICATION.md](VERIFICATION.md)。

## 開發與驗證

Node.js 24：

```sh
npm ci
npm test
npm run lint
npm run build
npm run test:browser
```

瀏覽器測試使用隔離環境及合成資料，需要 Playwright Chromium，或透過 `CHROME_PATH` 指定可執行檔。CI 已有 Chromium 安裝步驟。`SCREENSHOT_DIR` 可指定截圖位置，預設 `test-results/`。真實 OCR 測試使用 repo 內固定的合成 PNG，再轉 JPEG／WebP，不依賴主機中文字型。

`npm run test:webkit` 提供 WebKit 的完整備份、編輯與 PNG 測試入口，需要另外安裝 WebKit 與其系統依賴。WebKit 模擬不等於實體 iPhone Safari 驗收；本次環境未能啟動 WebKit，詳見驗證紀錄。

## 本機 OCR 批次審核

「辨識圖卡紀錄」支援每批最多 20 張 PNG／JPEG／WebP、單張 10 MB、合計 100 MB。辨識引擎、繁體中文及英文模型均由同一網站提供，無雲端辨識 API。可切換原圖、查看原文及所有候選；無法辨識的檔案會列出檔名與原因，不影響其餘檔案。

- 日期、睡眠、活動／步數、日照，以及餐飲、時間、明示金額／容量／數量等文字線索，先進候選審核。版面與文字辨識可能有誤，不保證全部欄位都能擷取。
- 全選全部、取消全選及逐筆選擇有效；可改日期、類別、時間、名稱、數量、金額、付款與食用狀態。
- 低信心、缺欄位、分類不明或付款不明者保存為待確認草稿，不進統計；有辨識依據的數值仍須最後確認才寫入。
- 不以同日期、同類別、名稱或時間就判定重複。比較全部紀錄事實（排除 ID、來源及修改時間），只有完全相同才跳過；每筆有結果代碼與具體理由。
- 同日不同睡眠／活動／日照預設留草稿，可明確選「另存」或選定目標、只補空白欄位。既有非空白事實不被覆寫。
- 餐飲與花費出現相同付款金額時，先保留草稿以避免重複計帳；若確實是獨立付款，需逐項核對並另外勾選「已排除重複記帳」。
- 最後確認及結果列出新增、補空白、重複、草稿、失敗與未選待處理；未選項目不混算為跳過。

「0 成功、22 跳過」可用歷史程式與合成資料重現，但沒有當時裝置資料／逐筆日誌，不能宣稱還原了當時每筆原因。

## 完整備份與跨裝置搬移

建議使用「匯出完整備份」→ 自行把檔案傳至另一裝置 →「還原完整／舊版備份」。**這是手動搬移，不是自動同步。**

完整 JSON 包含生活紀錄、OCR 草稿、照片原始 bytes、個人模板及其參考圖／配色／字體／欄數／排序、選取模板與深淺色偏好。格式為 `second-brain-lite-complete`，`backupVersion: 1`，紀錄另有獨立 schema version。限制 100 MB；圖片以 Base64 保存，因此檔案會比原圖大。備份未加密，請自行妥善保管。

還原前逐項預覽「新增／相同／衝突／無法解析」，可取消、只新增不覆寫，或明確選擇逐筆使用備份版本。保留本機衝突紀錄時，不會把匯入照片附到該紀錄。跳過新增紀錄／模板時，也跳過其依賴的新照片／模板選擇。格式錯誤有具體原因，其他合法項目仍可在確認後還原。

寫入前會保存本機回復快照，所有 v0.5 寫入配合 Web Locks；預覽後資料改變會拒絕還原。中途失敗回復原有內容；頁面中斷後啟動時檢查持久化回復日誌，未回復完成時停用寫入。**請先關閉其他舊版分頁**，舊版程式不會遵守新鎖。回復快照也占儲存空間；空間不足時可能拒絕操作，請勿清除瀏覽器資料。

原有「匯出紀錄 JSON／匯入 JSON 備份」仍保留作相容入口，不含照片與模板，匯入同 ID 時只保留本機。要逐項處理衝突或搬移所有內容，使用完整備份入口。

## 版本相容與紀錄原則

- 沿用 `second-brain-lite-v2` key 及現有照片／模板資料庫，不在啟動時自動改寫生活紀錄。可讀 v2～v7 紀錄 JSON；舊備份可經完整還原入口轉換，舊來源／修改時間不猜補。
- v0.5 新增或編輯會寫入 schema v7，保留來源與最後修改時間。原 ID 的補正更新原筆。v7 與完整備份無法匯回舊程式，升級前請留原備份；**不要在寫入 v7 後直接降級程式**。
- 購買、付款日期、食用狀態分開；購買／本人／家人／剩餘量分欄，缺值為未知，不從購買推算攝取。家人份量仍屬付款支出。
- 飲用中不算喝完，只有已飲用的實際容量納入液體合計。咖啡兌換預設 480 mL，可修改；券費不在兌換時重複計帳，額外實付另記花費。
- 購買、退費、回補分列。金額未知保留 null，已知部分稱已確認合計／淨支出，未付款不列入已付統計。前日買的東西不在食用當天再記帳。
- 睡眠沿用 main 的實際分段與日／週／月／六個月視圖；缺資料不補 0，沒有實際分段就不造睡眠週期。

## 手機與小誌

保留日期切換、快速新增、詳情編輯／刪除確認、深淺模式。手機輸入欄位最低 16px；OCR 批次工具可在長列表中使用。

新模板預設三欄，既有單欄／雙欄設定保留。小誌把飲食、飲品、花費分開，花費逐筆呈現，Canvas 依字寬換行，使用系統繁體中文字型。輸出尺寸固定 1080×1920。**單頁放不下完整內容時會明確提示並停用 PNG 下載**，不把省略明細的圖卡當完整日報交付；可改其他欄數或保留完整備份。多頁 PNG 待後續開發。照片尚未嵌入小誌 PNG，但完整備份會保存照片。
