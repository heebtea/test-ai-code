# Project Second Brain Lite v0.4

以 v0.3 為基底的繁體中文個人生活小誌。首次啟動為空白，資料保存在使用者的瀏覽器，不上傳或同步。桌面與手機可切換深淺模式。

## 開發與測試

Node.js 24：`npm ci`、`npm test`、`npm run lint`、`npm run build`、`npm run test:browser`。瀏覽器測試需要 Chrome，或設定 `CHROME_PATH`。CI 安裝 Playwright Chromium。截圖使用隔離的瀏覽器及合成資料，可使用 `SCREENSHOT_DIR` 指定輸出目錄。

## 使用方式

左右按鈕與日期選擇器切換日期；點擊摘要小卡可展開或收合明細，新增按鈕可直接記錄。空白數值代表未知，只有明確輸入 0 才是零。睡眠用起床日期；活動請記錄不重疊的區段，僅已完成計入摘要。咖啡僅已飲用計入飲用量；餐點狀態為未確認、部分、吃完，不把部分視為吃完。

展開當日時間軸可依時間查看事件，或新增重要事件。咖啡可填開始與結束飲用時間，餐點可填開始／結束時間；只有確認完成的紀錄才標示喝完／完食。時間軸只顯示有時間的紀錄。點選事件可查看詳情、編輯或刪除，並可加入一張照片。單張限 10 MB，支援 PNG、JPEG、WebP。照片只存在該瀏覽器的 IndexedDB，無跨裝置同步。刪除紀錄會嘗試刪除其照片。

「產生今日小誌」使用當前選取日期的紀錄，在本機產生 1080×1920 PNG。空白的數據區塊省略，未完成的餐點會標示狀態；過長的文字或超出篇幅的時間軸會截短或註明其餘事件。小誌不自動嵌入照片；預覽及匯出不修改紀錄。

## 付款與資料

餐點的用餐日、訂購日、實際付款日及食用狀態分別記錄。已付款且付款日已知才計入當日花費。新咖啡的購買日預設未知，請自行填實際日期；舊紀錄沒有購買日欄位時維持 v0.3 的紀錄日計費規則。咖啡券只在購券時記一次花費，兌換不重複扣款。餐點或咖啡請勿另外複製到花費，不同 ID 無法安全自動判定重複交易。

沿用 `second-brain-lite-v2` 的 localStorage key，未修改時不會自動寫回。接受 v2、v3、v4 JSON；新紀錄或匯入後使用 version 4。新備份無法匯回舊 v0.2/v0.3 程式，請保留原備份。匯入前顯示新增與衝突數，相同 ID 保留本機版本，不覆寫或刪除。資料毀損時停止寫入並可匯出原始內容；分頁偵測到資料已更新時拒絕覆寫。localStorage 沒有跨分頁交易能力，避免同時編輯。

**JSON 備份不包含照片**。照片保存在同一瀏覽器的 IndexedDB，換裝置或清除瀏覽器資料前請自行保存照片原檔。JSON 備份含私人資料，應自行妥善保管，不要提交至公開 GitHub。
