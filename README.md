# Project Second Brain Lite v0.4

以 v0.3 為基底的繁體中文個人生活小誌。首次啟動為空白，資料保存在使用者的瀏覽器，不上傳或同步。桌面與手機可切換深淺模式。

## 開發與測試

Node.js 24：`npm ci`、`npm test`、`npm run lint`、`npm run build`、`npm run test:browser`。瀏覽器測試需要 Chrome，或設定 `CHROME_PATH`。CI 安裝 Playwright Chromium。截圖使用隔離的瀏覽器及合成資料，可使用 `SCREENSHOT_DIR` 指定輸出目錄。

## 使用方式

左右按鈕與日期選擇器切換日期；點擊摘要小卡可展開或收合明細，新增按鈕可直接記錄。空白數值代表未知，只有明確輸入 0 才是零。睡眠用起床日期；活動請記錄不重疊的區段，僅已完成計入摘要。咖啡僅已飲用計入飲用量；餐點狀態為未確認、部分、吃完，不把部分視為吃完。

展開當日時間軸可依時間查看事件，或新增重要事件。咖啡可填開始與結束飲用時間，餐點可填開始／結束時間；只有確認完成的紀錄才標示喝完／完食。時間軸只顯示有時間的紀錄。點選事件可查看詳情、編輯或刪除，並可加入一張照片。單張限 10 MB，支援 PNG、JPEG、WebP。照片只存在該瀏覽器的 IndexedDB，無跨裝置同步。刪除紀錄會嘗試刪除其照片。

「產生今日小誌」使用當前選取日期的紀錄，在本機產生 1080×1920 PNG。空白的數據區塊省略，未完成的餐點會標示狀態；過長的文字或超出篇幅的時間軸會截短或註明其餘事件。小誌不自動嵌入照片；預覽及匯出不修改紀錄。

## 付款與資料

餐點的用餐日、訂購日、實際付款日及食用狀態分別記錄。已付款且付款日已知才計入當日花費。新咖啡的購買日預設未知，請自行填實際日期；舊紀錄沒有購買日欄位時維持 v0.3 的紀錄日計費規則。咖啡券只在購券時記一次花費，兌換不重複扣款。餐點或咖啡請勿另外複製到花費，不同 ID 無法安全自動判定重複交易。

沿用 `second-brain-lite-v2` 的 localStorage key，未修改時不會自動寫回。接受 v2～v6 JSON；一般紀錄沿用 version 5，包含待確認草稿或飲品時使用 version 6。新備份無法匯回舊 v0.2/v0.3/v0.4 程式，請保留原備份。匯入前顯示新增與衝突數，相同 ID 保留本機版本，不覆寫或刪除。資料毀損時停止寫入並可匯出原始內容；分頁偵測到資料已更新時拒絕覆寫。localStorage 沒有跨分頁交易能力，避免同時編輯。

**JSON 備份不包含照片**。照片保存在同一瀏覽器的 IndexedDB，換裝置或清除瀏覽器資料前請自行保存照片原檔。JSON 備份含私人資料，應自行妥善保管，不要提交至公開 GitHub。

## 匯入圖卡與互動模板

使用「匯入小誌圖卡」選擇本機 PNG、JPG、WebP（最多 10 MB），瀏覽器本機擷取常見色票。上傳圖像只作視覺參考，不辨識或匯入文字與數值。字體、裝飾、卡片欄數及每個區塊的對應順序由使用者手動確認；無自動辨識圖像中的分區、字體或插畫。內建「生活小誌」模板以使用者提供的 10/27 小誌的藍色頁首、彩色標籤、卡片和時間軸為風格參考，以獨立 HTML/CSS 元件重新繪製，沒有使用原圖或真實個人內容。

使用者可以儲存多個模板、切換、修改、還原未儲存的編輯或刪除模板。互動小誌依所選日期顯示紀錄，展開各區塊可新增或編輯。每日主題、亮點、身體、心情及待辦可新增「小誌文字」記錄；內容為明確輸入，包含在 JSON 備份中。範本圖片與設定保存在瀏覽器 IndexedDB，不包含在紀錄 JSON 備份中，無自動同步或跨裝置移轉，請保留原始圖卡與設定。

修改生活紀錄後使用 version 5 JSON，舊 v2、v3、v4 備份仍可讀取；v5 無法匯入舊版程式。PNG 預覽依所選模板的底色、標題色、字體、欄數及區塊順序重繪，不把原圖的私人數字或照片帶入 PNG。輸出為 1080×1920；過長的內容會截短並提示，請查看原始紀錄。

## 本機圖卡辨識

選擇「辨識圖卡紀錄」或在圖卡模板編輯中選擇「辨識圖卡紀錄」，PNG、JPG、WebP 圖片會在瀏覽器以同站提供的 Tesseract 語言模型辨識。圖片不會上傳或發送到第三方；首次使用需下載辨識引擎與語言檔。可查看 OCR 原文，辨識結果僅為候選，不會自動寫入。日期經兩次辨識一致，且睡眠、步數或日照數值符合信心門檻與文字線索時，沒有完全相同的既有紀錄時可預先勾選；餐飲、付款及不清楚內容仍須人工確認。OCR 對繁體中文、裝飾字體和複雜排版可能有誤，請對照原圖修正日期、數值、類別、時間及狀態。無法辨識的內容可使用「手動新增候選」。

可全選全部候選、只選可信項目或全部取消，候選預設收合；仍可逐筆展開、修改並選擇衝突處理：僅所有紀錄欄位完全相同（不含 ID）才跳過，同日同類但內容不同不等於重複；同日數據衝突先存草稿；合併須選擇既有紀錄，僅補空白、不覆蓋現有數據及付款／食用狀態；另存一筆需明確選擇，可能造成重複。確認摘要後才批次寫入，另一分頁變更會拒絕覆寫。餐點付款、咖啡付款方式與完成狀態不由 OCR 推定；匯入前請核對，券及前日購買飲品的日期尤其重要。

圖卡排版與分區差異可能影響自動候選；OCR 無法可靠關聯時間軸、餐點與花費，候選可能重複或缺漏。所有候選和原文皆應人工檢查；原圖不會放進 JSON 備份；已確認保存的草稿包含候選欄位及原文線索，會隨 v6 JSON 備份。私人圖片、原文與生活資料不應提交公開 repo。

匯入前與完成後顯示成功、重複跳過、暫存待確認、失敗數量及逐筆原因，只需一次總確認後才寫入。未選項目只算未選待處理，不列入跳過。已選但不完整、未核對、分類不明或付款／食用狀態不清楚的內容保存為草稿，可從「待確認草稿」重新開啟；草稿不計入正式統計。可能重複的同日同額付款也會先存草稿，避免餐飲及花費重複計帳。未選項目只留在目前視窗，關閉後請重新辨識。可信標記只是辨識輔助，仍請核對原圖；在不同排版與字體下可能辨識錯誤，缺乏足夠依據時一律留待確認。
