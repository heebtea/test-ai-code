## 測到的資料與安全條件

- iPhone 尺寸與桌面使用兩個隔離 browser context，localStorage／IndexedDB 不共用；透過相同合成 RPC 服務做資料交換。這是裝置行為模擬，**不是實體 iPhone Safari**。
- 頁面已載入時，兩台離線透過真正編輯表單修改同 ID；連線回復後顯示衝突，保留兩邊數值，明確選擇後收斂到同一紀錄。
- 失敗／重試、重複請求、首筆寫入回應丟失、在回應丟失後刪除、正在同步時本機再修改、停止同步、過期授權、不同帳戶、雲端遺失版本、同版本內容被修改、保留字 ID。
- 用戶端 pending／基底／tombstone；刪除不復活；同步失敗不把本機數值變成零或丟掉；本機提交配額錯誤回復、持久回復日誌及過期衝突拒絕。
- PGlite 執行**真正 PostgreSQL SQL**：匿名／未列入允許帳戶拒絕、兩個 user 的 ID 相同仍隔離、版本 CAS、重複請求不增版、tombstone、直接 table SELECT/DELETE 拒絕、AI client_id 拒絕、移除 allowlist 即時拒絕。auth.uid/auth.jwt 與 Auth users 是測試 scaffolding，**不是 Supabase 雲端 JWT 簽章／寄信驗證**。未測真實多連線 lock contention。
- AI handler 拒絕匿名／過期／撤銷／範圍外／POST、禁止 query owner；可信 adapter 收到伺服器 grant owner。只有合成 verifier，完整 OAuth/JWKS 尚未完成。
- 單日／日期區間、台灣午夜、跨月七天、閏年二月／十二月；事件、私人日誌、自由文字與未知欄位預設不外傳。
- 分享／下載使用同一 generatedAt；原始 localStorage bytes 完全相同；沒開同步時沒有外部請求；session token 不出現在 localStorage。
- 付款日帳務投影和攝取日紀錄分開；null 金額、兌換券、飲用中、本人／家人／剩餘量與退費保留。
- v2～v7 舊資料與 JSON／完整備份原回歸；跨 context 照片／模板 bytes 往返、預設不覆寫、替換須逐筆選擇、配額故障及過期預覽保護。
- 真實 Tesseract 引擎對 PNG/JPEG/WebP 合成圖卡產生 33 個候選；批次混合案例 5 新增／3 相同／14 草稿；沒有改回舊的全跳過邏輯。
- 三欄 PNG 尺寸 1080×1920、含支出明細、溢出檢查、模板及深淺色回歸。
