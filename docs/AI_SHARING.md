# AI 分享（v0.6 開發版）

從「分享資料給 AI」選單日、自訂區間、最近七天或當月 → 選分類 → 看完整預覽 → 複製／下載 JSON／系統分享。事件、私人日誌及自由文字敏感欄位預設不分享；照片／模板／草稿從不包含。

分享不寫入原始紀錄。快照保留 ID／狀態／原有修改時間，標示產生時間、日期區間、Asia/Taipei、來源模式與資料版本。付款日與攝取日分開，transactions 是同 ID 的投影，不可重複加總。

這是手動分享，不是 ChatGPT 即時連接；JSON 快照不是可還原的完整備份。先確認接收 App 與資料內容，已送出的副本不能遠端撤回。

完整流程、私人 Drive 路徑、Supabase 實作及尚未完成的 OAuth/MCP：[v0.6 交付說明](v0.6-private-sync.md)。
