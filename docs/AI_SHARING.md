# Second Brain Lite — 授權分享今日資料給 ChatGPT（開發版）

## 為什麼要做這個？

GitHub Pages 是靜態網站，Second Brain Lite 的個人日誌儲存在手機瀏覽器的 localStorage。
即使網址一樣，**ChatGPT、其他手機與電腦都不能直接讀取這份本機資料**。

本功能提供一條**由使用者選取並主動分享**的安全資料出口，不會默默同步、
也不會要求使用者交出帳密或把私人紀錄提交到公開 GitHub 專案。

## 使用方法（本分支合併並部署後）

1. 打開 Second Brain Lite，選到想分享的日期。
2. 按「分享今日資料給 AI」。
3. 預覽資料，勾選要分享的類別。**重要事件、日誌／心情預設不分享。**
4. 以下三選一：
   - **複製給 ChatGPT**：返回 ChatGPT，貼上並送出。貼上前可再刪除敏感資訊。
   - **系統分享**：在支援 Web Share API 的裝置上，可將該日 JSON 分享給其他 App 或個人雲端硬碟。
   - **下載今日 JSON**：自行上傳至 ChatGPT 或私人雲端硬碟（例如 Google Drive），再指定 ChatGPT 讀取。
5. ChatGPT 看見的是你送出的**當日快照**；之後在 Lite 增修紀錄，舊快照不會更新。

## 隱私和限制

- 無自動上傳、無背景任務、無新增帳號、無第三方追蹤；不寫入或變更 Lite 紀錄。
- 不含 IndexedDB 的照片（原備份也不包含照片）。
- 分享後的副本由接收 App 管理，可能長期保留，**無法在 Lite 內撤回已送出的資料**。
- 本機選取與預覽完全離線完成，真正送出要使用者再次操作。
- 「系統分享」能否直送 ChatGPT / Drive 取決於 iOS / Android 瀏覽器與 App 的支援。
- 這是**單次分享，不是可由 AI 隨時存取的私人雲端同步**。
- 不要將日誌 JSON commit 至此公開 Repository，不要把個人憑證儲存在前端程式碼。

## 後續：真正的私人同步

若需要「你問 ChatGPT 今天怎樣，它就能讀到 Lite 最新紀錄」，
需要額外的**私有後端／雲端硬碟授權**，並至少實作：
1. 使用者身份驗證、可撤銷的唯讀授權／存取權杖；
2. TLS、加密儲存、最小權限、允許撤銷與資料刪除；
3. 明確的同步開關、同步時間、範圍、錯誤狀態；
4. 可供 ChatGPT 使用的受驗證連接方式（不是只貼網站 URL）；
5. 針對失敗、重送、衝突、過期、被竊存取權杖等情境測試。

目前**尚未建立／部署上述後端**，因此不可聲稱 AI 已能讀取手機端即時資料。

## 驗證

- npm test
- npm run build
- 手機 Safari / Chrome 測試「複製」、「下載」、「系統分享」及資料分類篩選。
- 檢查同日紀錄不重複、其他日期不出現在分享快照中。
